# Gemini AI English Assistant para Anki

Extensão inteligente para geração automática do verso (Back) de cards de inglês usando a API do **Google Gemini**.

## Como Obter sua API Key do Google Gemini:
1. Acesse o [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Faça login com sua conta Google.
3. Clique em **"Create API key"** (Criar chave de API).
4. Copie a chave gerada e cole nas configurações desta extensão (`Ferramentas > Configurações Gemini AI`).

## Recursos:
- **Atalho no editor**: `Ctrl + Shift + G` para gerar o conteúdo do card instantaneamente.
- **Assíncrono**: Não trava a interface do Anki enquanto a IA pensa.
- **Prompt customizável**: Modifique o prompt como preferir na janela de configurações.
- **Suporte a múltiplos modelos**: Gemini 2.0 Flash, Gemini 1.5 Flash, Gemini 1.5 Pro, etc.
